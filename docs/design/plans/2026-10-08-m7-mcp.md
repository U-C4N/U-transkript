# M7 — MCP Server Implementation Plan

**Goal:** `pip install "u-transcript-max[mcp]"` adds the `utmax-mcp` command (also `python -m utmax.mcp`), a stdio MCP server that gives AI assistants five tools: `list_tracks`, `get_transcript`, `translate_transcript`, `list_videos` and `download`, with structured output, errors the model can read and act on, long transcripts read in parts, and downloads that report progress, stop when cancelled and never leave the configured download folder.

**Architecture:** `utmax/mcp/` is an interface over utmax's public API: `config.py` reads the environment (`UTMAX_MODEL`, `UTMAX_BASE_URL`, `UTMAX_DOWNLOAD_DIR`, `UTMAX_PROXY`), `server.py` builds an `MCPServer` (official `mcp` SDK) whose tools call one `utmax.Client` and return pydantic models, `download_file` runs a download on a worker thread and forwards its progress to the client, and `__init__.py`'s `main()` imports the SDK only when the command runs, so `import utmax` and `import utmax.mcp` stay free of third-party modules. The `mcp` extra pins `mcp>=2.2,<3`.

**Tech Stack:** Python ≥ 3.11 · the `mcp` SDK (2.2 or later: `MCPServer`, `Context`, `ToolError`, `ToolAnnotations`, the in-memory `Client`, `stdio_client`) with pydantic and anyio · pytest · ruff · mypy (strict) · uv.

**Spec:** `docs/design/2026-09-27-u-transcript-max-design.md` — read §2 (the `mcp` SDK fact), §4.1 (`list_videos`, `download`), §4.7 (MCP tools), §6 (errors and their `suggestion`), §7 (logging), §8 item 8 and §9 row M7 before starting. Prerequisites: M1–M5 are merged into `v4`; M7 calls `utmax.Client` (`list_tracks`, `fetch`, `translator`, `translate`, `bilingual`, `list_videos`, `download`) and `utmax.core.ids.parse_video_id`.

## Verified facts this plan relies on

**The `mcp` SDK** (2.3.0, released 2026-10-02, studied in a throwaway environment on 2026-10-08; the finished M7 also passes its tests and mypy with 2.2.0):

- `from mcp.server import MCPServer`; `MCPServer(name, title=..., instructions=..., version=..., website_url=...)`; `server.tool(annotations=...)` registers a function (sync functions run on an anyio worker thread, async ones on the event loop); the tool's name is the function's, its description the docstring; `server.run("stdio")` serves stdio. The constructor calls `logging.basicConfig`, which does nothing when the root logger already has handlers.
- Arguments come from the signature: `Annotated[T, pydantic.Field(description=..., ge=..., le=...)]` with a default gives a described, bounded, optional property; `Literal` gives an `enum`; arguments that fail the schema return an error result naming the field. Keyword-only parameters work. A parameter annotated `Context[Any, Any]` (`mcp.server.mcpserver.Context`, a generic pydantic model) receives the request context and is left out of the schema.
- A tool that returns a pydantic `BaseModel` gets that model's JSON schema as `outputSchema`, and every result carries it as `structured_content` plus a JSON text block. (`typing.TypedDict` outputs need `typing_extensions` below Python 3.12 when nested, so the server uses pydantic models.)
- `mcp.server.mcpserver.exceptions.ToolError(message)` → a result with `is_error=True` and the text `Error executing tool <name>: <message>`, logged at INFO; any other exception → `is_error=True` with only `Error executing tool <name>`, traceback logged at ERROR.
- `mcp.types.ToolAnnotations(read_only_hint=..., destructive_hint=..., idempotent_hint=..., open_world_hint=...)` (snake_case attributes, camelCase on the wire).
- `await ctx.report_progress(progress, total, message)` sends a progress notification (nothing when the caller asked for none); from any thread, `anyio.from_thread.run(coroutine_function, *args, token=token)` with `token = anyio.lowlevel.current_token()` taken on the event loop runs it there. `anyio.to_thread.run_sync(fn, abandon_on_cancel=True)` lets a cancelled caller return at once while the thread finishes by itself.
- Testing: `async with mcp.Client(server, raise_exceptions=True) as client` connects in memory; `await client.list_tools()` and `await client.call_tool(name, arguments, progress_callback=...)` return `ListToolsResult` and `CallToolResult` (`is_error`, `content`, `structured_content`); `mcp.stdio_client(mcp.StdioServerParameters(command=..., args=..., env=...))` with `mcp.ClientSession` starts a real stdio server. The stdio transport moves stray writes to file descriptor 1 onto stderr.
- `mcp` 2.3.0 depends on anyio, httpx2, jsonschema, mcp-types, opentelemetry-api, pydantic, pyjwt, python-multipart, pywin32 (Windows only), sse-starlette, starlette, typing-extensions, typing-inspection and uvicorn; the locked versions publish wheels for CPython 3.11–3.14 on Windows, Linux and macOS.

**Live** (2026-10-08, the finished server through the in-memory client): `list_tracks` returned the six tracks of `dQw4w9WgXcQ`; `list_videos` of `https://www.youtube.com/@RickAstleyYT/shorts` returned `kind` `shorts`, `count` 297 and the first three IDs; an `m4a` download of `dQw4w9WgXcQ` wrote 3 447 590 bytes into the download folder with seven progress notifications ending in `finished`, and a second call returned `skipped: true`; caption downloads were rate-limited (HTTP 429) after heavy testing, which `get_transcript` reported as an error with the suggestion "Wait before retrying, or use a rotating residential proxy with block_retries."

**Python and tools:** `python -S` leaves site-packages out of `sys.path` (how a test sees the command without the SDK); a module object in `sys.modules` whose `__getattr__` raises `ModuleNotFoundError` makes `from module import name` raise exactly that; `runpy.run_module("utmax.mcp", run_name="__main__")` runs `utmax/mcp/__main__.py`; `importlib.metadata.entry_points(group="console_scripts")` lists the project's commands (with `.dist.name`).

## Decisions (where the spec is silent or ambiguous)

1. **Tools** are closures over one `Client` and one `Config` inside `build_server(client=None, config=None)` (defaults: `Client(proxy=config.proxy)` and `Config.from_env()`); `download_file` is a module function so it can be tested without the SDK's client.
2. **Outputs** are pydantic models: `TracksOut` (`video: VideoOut`, `tracks: list[TrackOut]`), `TranscriptOut` (IDs, title, language, `is_generated`, `format`, `content`, `total_chars`, `offset`, `next_offset`), `TranslationOut` (`TranscriptOut` plus `translated_from` and `translator`), `VideosOut` (`title`, `source_id`, `kind`, `count`, `videos`) and `DownloadOut` (`path`, `size_bytes`, `video_id`, `title`, `container`, `embedded_subtitles`, `sidecars`, `skipped`). Durations are `duration_seconds`.
3. **Long transcripts** (the user chose this on 2026-10-08): `get_transcript` and `translate_transcript` take `offset` (default 0) and `max_chars` (default none: everything); a part ends after the last `\n` or space inside the window when there is one, and `next_offset` (null at the end) continues it.
4. **`get_transcript`'s `source`**: `any` (manual first, the default), `manual` or `generated`. **`list_videos`'s `kind`** defaults to none, so a channel link's tab decides, as for `utmax.list_videos` since M5.
5. **Models**: `translate_transcript` uses its `model` argument, else `UTMAX_MODEL`, else fails with a tool error that explains both; `UTMAX_BASE_URL` goes to `openai=` models only (`Config.translator_options`).
6. **Downloads**: the video ID is read first (an invalid one fails without a request); a file matching `* [<id>].<format>` in the folder is returned with `skipped: true` without any request (its title from the file name); otherwise the folder is created and `Client.download(video_id, folder, ...)` runs on a worker thread (`abandon_on_cancel=True`); cancelling the call sets the download's cancel event, which stops it and keeps its `.part` files for the next call. Progress is forwarded best-effort ("downloading: 1.5 of 3.4 MB", then the phase names), and a failure to report never stops the download.
7. **Annotations**: the four reading tools are read-only and open-world; `download` is open-world, not read-only, not destructive and idempotent.
8. **The command**: `utmax.mcp.main()` imports `utmax.mcp.server` when called; a missing SDK module (`anyio`, `mcp`, `mcp_types`, `pydantic`, `pydantic_core`) becomes `SystemExit('utmax-mcp needs the MCP SDK: pip install "u-transcript-max[mcp]"')`, other import errors propagate. `run()` switches stderr to UTF-8, logs at INFO to stderr, reads `Config.from_env()`, builds `Client(proxy=...)` (an unusable proxy exits with the error and its suggestion) and serves stdio.
9. **Packaging and CI**: the extra is `mcp = ["mcp>=2.2,<3"]` (2.2.0 and 2.3.0 verified) and the console script `utmax-mcp = "utmax.mcp:main"` (Task 5, together with `main`); CI's lint job runs `uv sync --locked --all-extras` because mypy checks `utmax.mcp.server` against the SDK's types; the core job (no extras) skips the SDK tests through `collect_ignore` in `tests/mcp/conftest.py`.
10. **Layout** (spec §3): `mcp/__init__.py __main__.py config.py server.py`; the tests live in `tests/mcp/`, including the live checks (they need the SDK, which `tests/live/` must not import).

"""The MCP server's settings, read from environment variables.

- ``UTMAX_MODEL``: the translation model (``"provider=model-id"``) used when a call names none.
- ``UTMAX_BASE_URL``: the server of ``openai=`` models (Ollama, LM Studio, ...).
- ``UTMAX_DOWNLOAD_DIR``: where downloads go; default ``~/Downloads/utmax``.
- ``UTMAX_PROXY``: an ``http://[user:password@]host:port`` proxy for YouTube.

utmax itself reads ``UTMAX_FFMPEG`` (the ffmpeg for MP3 files) and the provider SDKs read their
API keys (``ANTHROPIC_API_KEY``, ``OPENAI_API_KEY``, ``GEMINI_API_KEY``, ``OPENROUTER_API_KEY``).
"""

from __future__ import annotations

import os
from collections.abc import Mapping
from dataclasses import dataclass, field
from pathlib import Path

__all__ = ["Config", "default_download_dir"]


def default_download_dir() -> Path:
    """``~/Downloads/utmax``."""
    return Path.home() / "Downloads" / "utmax"


@dataclass(frozen=True, slots=True)
class Config:
    """What the tools need beyond their arguments; the model never chooses a path."""

    model: str | None = None
    base_url: str | None = None
    download_dir: Path = field(default_factory=default_download_dir)
    proxy: str | None = None

    @classmethod
    def from_env(cls, environ: Mapping[str, str] = os.environ) -> Config:
        """The settings in ``environ``; unset and empty variables keep the defaults."""

        def value(name: str) -> str | None:
            text = environ.get(name, "").strip()
            return text or None

        directory = value("UTMAX_DOWNLOAD_DIR")
        return cls(
            model=value("UTMAX_MODEL"),
            base_url=value("UTMAX_BASE_URL"),
            download_dir=Path(directory).expanduser() if directory else default_download_dir(),
            proxy=value("UTMAX_PROXY"),
        )

    def translator_options(self, model: str) -> dict[str, str]:
        """Options for ``utmax.translator(model)``: ``base_url`` applies to ``openai=`` models."""
        provider = model.partition("=")[0].strip().lower()
        if self.base_url is not None and provider == "openai":
            return {"base_url": self.base_url}
        return {}

def build_server(client: Client | None = None, config: Config | None = None) -> MCPServer:
    """The MCP server with utmax's tools, using ``client`` (by default one built from
    ``config``) and ``config`` (by default read from the environment)."""
    settings = config if config is not None else Config.from_env()
    youtube = client if client is not None else Client(proxy=settings.proxy)
    server = MCPServer(
        "utmax",
        title="u-transcript max",
        instructions=INSTRUCTIONS,
        version=__version__,
        website_url="https://github.com/U-C4N/U-transkript",
    )
    reads = ToolAnnotations(read_only_hint=True, open_world_hint=True)

    @server.tool(annotations=reads)
    def list_tracks(video: VideoArg) -> TracksOut:
        """List the subtitle tracks of a YouTube video: language, written by people or
        generated automatically, and whether YouTube can translate it."""
        with tool_errors():
            tracks = youtube.list_tracks(video)
        return TracksOut(
            video=_video(tracks.video),
            tracks=[
                TrackOut(
                    language_code=track.language_code,
                    language=track.language,
                    is_generated=track.is_generated,
                    is_translatable=track.is_translatable,
                )
                for track in tracks
            ],
        )

    @server.tool(annotations=reads)
    def get_transcript(
        video: VideoArg,
        *,
        languages: LanguagesArg = None,
        format: FormatArg = "txt",
        source: TrackSourceArg = "any",
        offset: OffsetArg = 0,
        max_chars: MaxCharsArg = None,
    ) -> TranscriptOut:
        """Get the transcript (subtitles) of a YouTube video, by default in the spoken language
        with subtitles written by people preferred over automatic ones."""
        with tool_errors():
            transcript = youtube.fetch(
                video,
                languages,
                include_manual=source != "generated",
                include_generated=source != "manual",
            )
            return transcript_out(transcript, format, offset, max_chars)

    @server.tool(annotations=reads)
    def translate_transcript(
        video: VideoArg,
        to: ToArg,
        *,
        model: ModelArg = None,
        languages: LanguagesArg = None,
        format: FormatArg = "txt",
        bilingual: Annotated[
            bool, Field(description="Show each original line above its translation.")
        ] = False,
        instructions: InstructionsArg = None,
        offset: OffsetArg = 0,
        max_chars: MaxCharsArg = None,
    ) -> TranslationOut:
        """Translate the transcript of a YouTube video with an AI model, keeping its timing."""
        spec = model or settings.model
        if spec is None:
            raise ToolError(
                "No translation model is configured. Suggestion: pass model as "
                "provider=model-id (for example claude=claude-opus-5), or set UTMAX_MODEL in "
                "the MCP server's environment."
            )
        with tool_errors():
            original = youtube.fetch(video, languages)
            translator = youtube.translator(spec, **settings.translator_options(spec))
            translation = youtube.translate(
                original, to, model=translator, instructions=instructions
            )
            result = youtube.bilingual(original, translation) if bilingual else translation
            page = transcript_out(result, format, offset, max_chars)
        return TranslationOut(
            **page.model_dump(),
            translated_from=result.translated_from,
            translator=result.translator,
        )

    @server.tool(annotations=reads)
    def list_videos(source: CollectionArg, kind: KindArg = None, limit: LimitArg = 50) -> VideosOut:
        """List the videos of a YouTube playlist or channel, in YouTube's order."""
        with tool_errors():
            videos = youtube.list_videos(source, kind=kind, limit=limit)
        return VideosOut(
            title=videos.title,
            source_id=videos.source_id,
            kind=videos.kind,
            count=videos.video_count,
            videos=[
                VideoEntryOut(
                    video_id=entry.video_id,
                    title=entry.title,
                    duration_seconds=entry.duration,
                    channel=entry.channel,
                    channel_id=entry.channel_id,
                    index=entry.index,
                    url=entry.url,
                )
                for entry in videos

@contextmanager
def tool_errors() -> Iterator[None]:
    """Turn utmax errors (and file system errors) into tool errors the model can read."""
    try:
        yield
    except UTMaxError as error:
        raise ToolError(f"{error} Suggestion: {error.suggestion}") from error
    except OSError as error:
        raise ToolError(str(error)) from error


def transcript_out(
    transcript: Transcript, format: FormatName, offset: int, max_chars: int | None
) -> TranscriptOut:
    """The tool output for ``transcript``: its text in ``format``, from ``offset`` on and cut
    after ``max_chars`` characters at a line or word end."""
    text = transcript.to(format)
    content, next_offset = _page(text, offset, max_chars)
    return TranscriptOut(
        video_id=transcript.video.video_id,
        title=transcript.video.title,
        language_code=transcript.language_code,
        language=transcript.language,
        is_generated=transcript.is_generated,
        format=format,
        content=content,
        total_chars=len(text),
        offset=offset,
        next_offset=next_offset,
    )


def _page(text: str, offset: int, max_chars: int | None) -> tuple[str, int | None]:
    if max_chars is None or offset + max_chars >= len(text):
        return text[offset:], None
    end = offset + max_chars
    cut = max(text.rfind("\n", offset, end), text.rfind(" ", offset, end))
    if cut > offset:
        end = cut + 1
    return text[offset:end], end

        url=info.url,

async def download_file(
    client: Client,
    directory: Path,
    video: str,
    *,
    format: Container = "mp4",
    quality: Quality = "compat",
    subtitles: list[str] | None = None,
    subtitle_mode: SubtitleMode = "embed",
    report: Callable[[Progress], Coroutine[Any, Any, None]] | None = None,
) -> DownloadOut:
    """Download ``video`` into ``directory`` on a worker thread, unless it is already there.

    ``report`` receives the download's progress on the event loop. When the caller is
    cancelled, the download stops and keeps its partial files, so the next call resumes it.
    """
    with tool_errors():
        video_id = parse_video_id(video)
    existing = _existing_download(directory, video_id, format)
    if existing is not None:
        return DownloadOut(
            path=str(existing),
            size_bytes=existing.stat().st_size,
            video_id=video_id,
            title=existing.name.removesuffix(f" [{video_id}].{format}"),
            container=format,
            embedded_subtitles=[],
            sidecars=[],
            skipped=True,
        )
    token = anyio.lowlevel.current_token()
    cancel = threading.Event()

    def forward(update: Progress) -> None:
        if report is None:
            return
        try:
            anyio.from_thread.run(report, update, token=token)
        except Exception:  # progress is best effort; it must never stop a download
            log.debug("could not report download progress", exc_info=True)

    def work() -> DownloadResult:
        directory.mkdir(parents=True, exist_ok=True)
        return client.download(
            video_id,
            directory,
            format=format,
            quality=quality,
            subtitles=subtitles,
            subtitle_mode=subtitle_mode,
            progress=forward,
            cancel=cancel,
        )

    try:
        with tool_errors():
            result = await anyio.to_thread.run_sync(work, abandon_on_cancel=True)
    except anyio.get_cancelled_exc_class():
        cancel.set()
        raise
    return DownloadOut(
        path=str(result.path),
        size_bytes=result.size_bytes,
        video_id=result.video.video_id,
        title=result.video.title,
        container=result.container,
        embedded_subtitles=list(result.embedded_subtitles),
        sidecars=[str(path) for path in result.sidecars],
        skipped=False,
    )

# A block reaches the model as "<message> Suggestion: <suggestion>". The message varies (HTTP 429,
# a CAPTCHA page, the bot check) but the suggestion comes from the error class, so it tells a
# RequestBlocked or IpBlocked from any other error, as tests/live/conftest.py does by type.
BLOCKED = (RequestBlocked.suggestion, IpBlocked.suggestion)


def call(server: Any, name: str, arguments: dict[str, Any]) -> dict[str, Any]:
    async def main() -> CallToolResult:
        async with MCPClient(server, raise_exceptions=True) as client:
            return await client.call_tool(name, arguments)

    result = anyio.run(main)
    if result.is_error:
        text = " ".join(block.text for block in result.content if block.type == "text")
        if any(suggestion in text for suggestion in BLOCKED):
            pytest.skip(f"YouTube is blocking this IP address: {text}")
        pytest.fail(text)
    assert result.structured_content is not None
    return result.structured_content

    assert page["total_chars"] > 200

def run() -> None:
    """Serve the tools over stdio (the ``utmax-mcp`` command); logs go to stderr."""
    if isinstance(sys.stderr, io.TextIOWrapper):
